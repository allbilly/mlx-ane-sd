# Compact M1 full-ANE reference

This 5.54 MB kit preserves the measured Qwen3-0.6B full-ANE kernels without
learned weight banks or captured tensor binaries. Setup, pinned `hf download`
commands, reconstruction, verification and benchmarks are documented once in
[the Asahi guide](../../asahi/README.md).

## Contents

- Five compressed kernel templates with learned coefficients zeroed: two
  14-layer target chunks, three-layer DFlash draft, context projector and
  shared 151,936-token vocabulary head.
- Compact LUT6 quantizer boundaries, rounding corrections and packing recipes.
  Palette means and cluster indices are rebuilt from the public BF16 weights.
- Original MIL, compiler tensor geometry and Linux BAR/buffer plans. Templates
  preserve command streams, symbols and fixed activation tables; the decoder
  regenerates all 6,034 tasks and 763,960 register writes.
- Real prompt/cache traces and hashes for 72 calls / 588 output tensors. Inputs
  are regenerated by the host loop. No input/output payloads are stored.
- A 40 KB fixed mathematical RoPE table that preserves FP16 rounding across
  NumPy versions, without storing learned weights.
- Checkpoint revisions/hashes, complete reconstructed HWX hashes and the
  original native benchmark identity.

[reconstruction.json](reconstruction.json) records byte-identical reconstruction
of all five complete HWX files. Its Linux-verification fields and those in
`manifest.json` describe kit creation before Linux testing. Later hardware
execution is established by the
[Asahi confirmation receipt](../../notes/m1_linux_full_ane_bench_uclamp_confirm_warm100_20261006.json).
The [macOS validation receipt](../../notes/m1_compact_reference_validation.json)
checks regenerated inputs against the original CoreML ANE goldens.

The exports are offline compiler HWX files. Direct `_ANEClient` loading on
macOS rejected them at stage 4 with status `0x1`; equivalent MIL ran on ANE.
Asahi executes all five exports and matches their goldens. This does not
identify the executable loaded internally by CoreML on macOS.

Complete runtime HWX and downloaded checkpoints are disposable assets under
ignored `.asahi/`. The kit does not include embeddings, compiler `weight.bin`,
full weight-bearing HWX, or bulk surface dumps. Older capture archives remain
only as documented history on the research branch.
